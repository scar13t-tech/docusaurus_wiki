# Prowlarr

Prowlarr is an indexer manager used with applications like Sonarr, Radarr, Lidarr, and Readarr.

## What Prowlarr Does

Prowlarr helps manage indexers in one place and syncs them to your other media applications.

## Installation Options

Prowlarr can be installed in several ways depending on your platform:

- TrueNAS Apps
- TrueNAS Custom App
- Docker Compose
- Unraid Community Apps
- Proxmox LXC or Docker VM
